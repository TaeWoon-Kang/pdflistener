# 한국어 소개 문구

2026-09-29. 사용자가 선택한 기준은 “Mac에서 듣는 영어 논문. 필요한 문장부터, 원하는 속도로.”다.
짧은 소개 제목에 구체적인 기능 설명을 붙인다. 말투를 일괄적으로 해요체로 바꾸지 않는다.

## 참고한 제품 소개

- [Apple Books](https://www.apple.com/kr/apple-books/): 짧은 제목 아래에서 실제 독서 기능과 사용 조건을 설명하는 구성.
- [Apple Pages](https://www.apple.com/kr/pages/): 기능별 제목과 사용 행동을 설명하는 본문의 역할 구분.
- [알PDF](https://altools.co.kr/product/ALPDF): 기능 이름과 지원 환경을 구분해 안내하는 방식.

위 구성과 설명 방식을 참고했다. 다른 서비스의 고유 문구, 성능 수치나 기능을 가져오지 않았다.
화려한 수식어와 말장난, 긴 기능 나열은 따르지 않는다.

## 문구 기준

- 제목은 짧은 소개 문구로 쓴다. 억지로 운율을 맞추거나 모든 제목을 권유형으로 만들지 않는다.
- 설명은 무엇을 하는 기능인지 먼저 밝히고 차분한 합니다체로 쓴다.
- 추상적인 ‘흐름’, ‘여유’, ‘경험’을 반복하는 대신 문장 선택·재생 속도·제외 항목을 구체적으로 설명한다.
- ‘핵심만’, ‘본문만’ 같은 표현으로 요약 기능이나 완벽한 자동 제외를 약속하지 않는다.
- 웹의 음성 샘플과 앱의 실제 동작, 현재 출시 준비 상태를 구분한다.
- 라이선스 원문과 상세 고지, 영문 문구, 폰트와 화면 구조는 이번 변경 범위에 포함하지 않는다.

주요 변경: ‘논문 본문에 집중.’, ‘듣는 위치를 한눈에.’, ‘인터넷 없이도, 내 Mac에서.’
오프라인 설명에는 앱에 음성 모델이 포함된다는 조건을 유지한다.

검증: 7개 Node 검사와 실제 Chrome 통합 검사. 한국어·영어 320–1440px,
음성 재생·문장 이동·언어 전환·키보드·JavaScript 없는 표시를 확인한다.
영문 문구 및 상세 라이선스 설명은 변경 전 값과 비교한다.

문구는 Claude와 AGY의 검토를 거쳤다. 제안은 실제 화면과 기능에 맞는 경우에만 반영한다.
웹 샘플의 논문 모드 안내는 샘플에 있는 저자 정보·그림 설명만 설명한다.
